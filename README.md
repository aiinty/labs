Репозиторий с учебными материалами по дисциплинам

## Структура

```text
.
├── андр/               # § 01.03.01 «Андроид студия»
│
├── кп пм.02/           # КП по ПМ.02 Осуществление интеграции программных модулей
│
├── мобпри/             # § 01.03.03 «Разработка мобильного приложения»
│   ├── _картинки/          # Изображения для материалов
│   ├── pdf/                # PDF-версии материалов
│   ├── доп материалы/      # Дополнительные материалы
│   └── *.md                # Уроки и лабораторные работы
│
├── прму/               # МДК 02.04 «Программирование для мобильных устройств»
│   ├── _картинки/          # Изображения для материалов

```

## Обратная связь

Если нашли ошибку, неточность или хотите предложить улучшение материала — создайте **[Issue](https://github.com/aiinty/labs/issues)** в этом репозитории (нужен будет аккаунт)

Можете использовать их как комментарии, а также можно сообщить, например, об:

* ошибках в тексте или коде
* непонятных местах
* неработающих примерах
* предложениях по улучшению материалов
* других вопросах по содержанию
* и тд и тп
