## Часть 1. Теория

Для работы с файлами в C# используется класс `File`.

Основные методы класса `File`:

- `File.ReadAllText(path)` - читает весь текст из файла
- `File.WriteAllText(path, text)` - записывает текст в файл
- `File.Exists(path)` - проверяет, существует ли файл

Чтобы пользователь мог выбрать файл, в WPF используются диалоговые окна `OpenFileDialog` и `SaveFileDialog`.

Операции с файлами могут завершиться ошибкой, например если файл недоступен. Поэтому их следует выполнять в блоке `try-catch`.

## Часть 2. Практическая работа

Создадим простой текстовый редактор: пользователь сможет открыть текстовый файл, изменить его содержимое и сохранить результат.

### Шаг 1. Создаем интерфейс

В `MainWindow.xaml` разместите внутри окна следующую разметку:

```xml
<StackPanel Margin="16">
    <TextBlock Text="Блокнот" FontSize="22" FontWeight="Bold" Margin="0,0,0,10"/>

    <WrapPanel Margin="0,0,0,10">
        <Button Name="OpenButton" Content="Открыть файл" Click="OpenButton_Click" Padding="10,5" Margin="0,0,8,0"/>
        <Button Name="SaveButton" Content="Сохранить как..." Click="SaveButton_Click" Padding="10,5"/>
    </WrapPanel>

    <TextBox Name="EditorTextBox" Height="300" AcceptsReturn="True" AcceptsTab="True" 
                TextWrapping="Wrap" VerticalScrollBarVisibility="Auto"/>
</StackPanel>
```

`EditorTextBox` - поле, в котором пользователь будет редактировать текст. Кнопки вызывают обработчики, которые мы добавим далее.

### Шаг 2. Открываем файл

Добавьте в класс `MainWindow` обработчик кнопки "Открыть файл":

```csharp
private void OpenButton_Click(object sender, RoutedEventArgs e)
{
    OpenFileDialog dialog = new OpenFileDialog();
    dialog.Filter = "Текстовые файлы (*.txt)|*.txt|Все файлы (*.*)|*.*";

    if (dialog.ShowDialog() != true)
        return;

    try
    {
        if (!File.Exists(dialog.FileName))
        {
            MessageBox.Show("Файл не найден");
            return;
        }

        EditorTextBox.Text = File.ReadAllText(dialog.FileName);
    }
    catch (Exception ex)
    {
        MessageBox.Show($"Не удалось открыть файл: {ex.Message}");
    }
}
```

`OpenFileDialog` позволяет выбрать файл, а `dialog.FileName` содержит его путь. Метод `File.ReadAllText()` читает текст и помещает его в поле редактора.

> **Проверьте:** запустите приложение и откройте любой текстовый файл

### Шаг 3. Сохраняем текст

Добавьте обработчик кнопки "Сохранить как...":

```csharp
private void SaveButton_Click(object sender, RoutedEventArgs e)
{
    SaveFileDialog dialog = new SaveFileDialog();
    dialog.Filter = "Текстовые файлы (*.txt)|*.txt|Все файлы (*.*)|*.*";
    dialog.DefaultExt = ".txt";
    dialog.AddExtension = true;

    if (dialog.ShowDialog() != true)
        return;

    try
    {
        File.WriteAllText(dialog.FileName, EditorTextBox.Text);
        MessageBox.Show("Файл сохранен");
    }
    catch (Exception ex)
    {
        MessageBox.Show($"Не удалось сохранить файл: {ex.Message}");
    }
}
```

`SaveFileDialog` позволяет выбрать имя и место сохранения. Метод `File.WriteAllText()` записывает текст в файл. Если файл с таким именем уже существует, его содержимое будет заменено.
