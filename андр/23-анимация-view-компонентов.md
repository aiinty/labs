# Лабораторная работа №23

## Анимация View-компонентов

### О чем лабораторная?

Анимация помогает показать изменение состояния интерфейса и сделать переходы понятнее. В Android простую анимацию можно создать непосредственно для `View`, изменяя его прозрачность, положение, размер или поворот.

Сегодня добавим анимацию в экран с изображением или графикой.

### Часть 1. Анимация появления

Разместите на экране:

- `ImageView`
- `TextView`
- кнопку "Показать"

Получите изображение в Java:

```java
ImageView imageView = findViewById(R.id.imageView);
```

Для плавного появления используйте:

```java
imageView.setAlpha(0f);
imageView.animate()
        .alpha(1f)
        .setDuration(800)
        .start();
```

`alpha` задает прозрачность, `setDuration()` - длительность в миллисекундах, а `start()` запускает анимацию.

> Сделайте так, чтобы изображение плавно появлялось после нажатия кнопки. До нажатия оно должно быть скрыто или полностью прозрачным.

---

### Часть 2. Двигаем компонент

Добавьте вторую кнопку и переместите изображение по горизонтали:

```java
imageView.animate()
        .translationX(150f)
        .setDuration(600)
        .start();
```

Для возврата используйте значение `0f`:

```java
imageView.animate()
        .translationX(0f)
        .setDuration(600)
        .start();
```

## Требования

1. На экране есть компонент, к которому применяется анимация
2. Реализована анимация появления, исчезновения или изменения положения
3. Используется `.animate()`
4. Есть кнопка запуска анимации
5. Реализован возврат в исходное состояние
6. Приложение запускается без ошибок
