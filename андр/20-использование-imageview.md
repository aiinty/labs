# Лабораторная работа №20

## Использование ImageView

### О чем лабораторная?

`ImageView` предназначен для отображения изображения в интерфейсе. Один и тот же ресурс можно показать с разным масштабированием и в разных частях экрана.

Сегодня создадим карточку каталога с изображением, названием и описанием.

### Часть 1. Создаем карточку

Добавьте в вертикальный `LinearLayout`:

- `ImageView`
- `TextView` для отображения названия картинки
- `TextView` для отображения названия картинки
- кнопку "Показать другое"

Пример `ImageView`:

```xml
<ImageView
    android:layout_width="match_parent"
    android:layout_height="220dp"
    android:src="@drawable/kakoetophoto"
    android:scaleType="centerCrop"
    android:contentDescription="@string/opisanie" />
```

- `src` задает изображение
- `scaleType` определяет способ его размещения
- `contentDescription` описывает изображение для специальных возможностей (например, экранный диктор или режим для слабовидящих)

> Добавьте в проект какую-то картинку и отобразите ее в `ImageView`. Все строки вынесите в `strings.xml`.

---

### Часть 2. Сравниваем способы масштабирования

По очереди проверьте значения:

- `center` - изображение сохраняет размер и располагается по центру
- `centerInside` - изображение полностью помещается внутри области
- `centerCrop` - область заполняется, лишние края могут обрезаться
- `fitCenter` - изображение помещается целиком с сохранением пропорций

Обычно лучшим решенияем является сохранить пропорции у самой картинки и выбрать подходящий `scaleType`.

> Выберите вариант, который лучше подходит для вашей карточки

---

### Часть 3. Меняем изображение по нажатию

Получите `ImageView` в Java:

```java
ImageView imageObject = findViewById(R.id.imageObject);
Button button = findViewById(R.id.btnChangeImage);
```

В обработчике кнопки можно сделать так, чтобы картинка менялась по нажатию:

```java
button.setOnClickListener(v -> {
    imageObject.setImageResource(R.drawable.another_object);
});
```

В записи Java между `R.drawable` и именем ресурса используется точка:

```java
R.drawable.another_object
```

> Добавьте минимум два изображения и сделайте переключение между ними.

### Самостоятельная часть

Сделайте так, чтобы по нажатию кнопки для каждой картинки отображался еще и свой текст.

## Требования

1. На экране отображается `ImageView` с изображением из `drawable`
2. Указан подходящий `scaleType`
3. У изображения есть `contentDescription`
4. На экране есть название и описание объекта
5. Кнопка изменяет изображение минимум на два варианта
6. Тексты вынесены в строковые ресурсы
7. Приложение запускается без ошибок
