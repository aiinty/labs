# ПП.02.01. Ролевая игра «Проектная группа»

## Состав команды

Одна проектная группа состоит из **3-4 студентов**. В начале практики группа распределяет роли между участниками и выбирает **менеджера** проекта.

В рамках проектной группы есть следующие роли:

- Менеджер проекта
- Разработчик базы данных
- Разработчик серверной части
- Разработчик клиентской части
- Дизайнер
- Тестировщик базы данных
- Тестировщик серверной части
- Тестировщик клиентской части
- Технический писатель

Менеджер проекта:

- организует работу проектной группы
- участвует в распределении задач и контроле их выполнения
- обеспечивает согласованность проектной документации
- представляет результаты проектной деятельности
- участвует в выполнении общих задач наравне с остальными участниками
- осуществляет ежедневную оценку КТУ участников группы

## Ежедневная оценка участия в команде

По итогам **каждого дня** менеджер проекта заполняет файл `Рейтинг.xlsx`.

В файле предусмотрено четыре листа:

| Лист | Назначение |
| --- | --- |
| `Распределение Ролей` | Фиксация ролей участников группы по дням практики |
| `КТУ Группы` | Ежедневная оценка КТУ участников группы по аспектам |
| `Рейтинг участников команды` | Учет результатов выполнения задач ролей и участия в проекте |
| `Итоговый Рейтинг` | Свод КТУ и рейтинга каждого участника за каждый день |

## Как проставлять КТУ

**КТУ - коэффициент трудового участия.**

Он показывает долю вклада каждого участника в выполнение конкретной задачи.

Коэффициент указывается отдельно для каждого студента по каждой задаче. Используйте значения от `0` до `1` с шагом `0,1`.

| КТУ | Когда устанавливается |
| ---: | --- |
| 1,0 | Студент выполнил задачу полностью или единолично отвечает за ее результат |
| 0,9 | Студент выполнил практически всю задачу, небольшой фрагмент выполнен другим участником |
| 0,8 | Студент выполнил основную часть задачи, остальная часть распределена между другими участниками |
| 0,7–0,6 | Студент выполнил большую часть задачи, но существенная часть принадлежит другим участникам |
| 0,5 | Вклад участников в задачу примерно равный |
| 0,4–0,2 | Студент выполнил отдельный небольшой фрагмент задачи |
| 0,1 | Студент выполнил минимальное действие в рамках задачи |
| 0,0 | Студент не участвовал в выполнении задачи |

> **Для каждой задачи сумма КТУ в сумме должен быть равен `1,0`**

## Итоговая оценка проектной группы

По завершении практики оцениваются:

- качество разработанного программного продукта
- качество документации
- качество презентации и доклада
- индивидуальный вклад каждого участника проектной группы (КТУ/рейтинг)
