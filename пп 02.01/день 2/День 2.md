# День 2. Проектирование программного продукта

## Задание на День 2

1. Спроектировать макеты основных экранов приложения
2. Определить навигацию между экранами
3. Настроить серверную часть PocketBase
    - Создать коллекции по сущностям ER-диаграммы
    - Настроить правила доступа к коллекциям
    - Наполнить базу данных тестовыми данными
4. Определить запросы к API, необходимые приложению
5. Создать коллекцию запросов в Hoppscotch
6. Начать разработку Android-приложения

**Результаты работы:**

- Разработнные макеты экранов с навигацией между ними
- Настроенная и заполеннная база данных PocketBase
- Созданная коллекция API-запросов в Hoppscotch
- Начальная версия Android-приложения
