# PocketBase для учебной практики

**Информация для руководителя практики**

Запускается отдельный экземпляр PocketBase для каждой группы. Версия PocketBase задается в `Dockerfile` параметром `PB_VERSION`

При запуске контейнера файл `entrypoint.sh` автоматически создает/обновляет админа соответствующей группы

Каждая группа имеет свое пространство:

| Группа | Адрес при обращении к серверу | Порт | Администратор |
| --- | --- | --- | ---: |
| 1 | `http://<адрес-сервера>:8081` | 8081 | `team1@oat.ru` |
| 2 | `http://<адрес-сервера>:8082` | 8082 | `team2@oat.ru` |
| 3 | `http://<адрес-сервера>:8083` | 8083 | `team3@oat.ru` |
| 4 | `http://<адрес-сервера>:8084` | 8084 | `team4@oat.ru` |
| 5 | `http://<адрес-сервера>:8085` | 8085 | `team5@oat.ru` |
| 6 | `http://<адрес-сервера>:8086` | 8086 | `team6@oat.ru` |
| 7 | `http://<адрес-сервера>:8087` | 8087 | `team7@oat.ru` |
| 8 | `http://<адрес-сервера>:8088` | 8088 | `team8@oat.ru` |
| 9 | `http://<адрес-сервера>:8089` | 8089 | `team9@oat.ru` |
| 10 | `http://<адрес-сервера>:8090` | 8090 | `team10@oat.ru` |

Вместо `<адрес-сервера>` IP-адрес или домен сервера. Сервер может быть размещен на удаленной машине, или внутри локальной сети кабинета/колледжа

**Пароль администратора по умолчанию для всех:**

```text
admin12345
```

## Требования

На сервере должны быть установлены:

- Docker
- Docker Compose Plugin (`docker compose`)
- открытые для студентов порты `8081–8090` или реверс-прокси, если идет работа по домену

## Запуск

Перейдите в каталог `pocketbase` и выполните:

```bash
docker compose up -d --build
```

Проверить состояние контейнеров:

```bash
docker compose ps
```

Посмотреть журналы:

```bash
docker compose logs -f
```

Остановить сервисы без удаления данных:

```bash
docker compose down
```

Если необходимо удалить данные всех команд, то:

```bash
docker compose down -v
```

## Админ-панель

После запуска административная панель каждой группы доступна по адресу:

```text
http://<адрес-сервера>:8081/_/
http://<адрес-сервера>:8082/_/
...
http://<адрес-сервера>:8090/_/
```

Учетная запись администратора создается автоматически при старте контейнера
через команду `superuser upsert`. При перезапуске контейнера учетная запись
сохраняется, а пароль синхронизируется со значением из `docker-compose.yml`

## API

Базовый адрес API для группы 1:

```text
http://<адрес-сервера>:8081/api/
```

Для остальных групп меняется только порт. Например, для группы 4:

```text
http://<адрес-сервера>:8084/api/
```
