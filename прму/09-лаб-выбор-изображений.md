# Лабораторная работа №9

## Выбор изображений из галереи устройства

### О чем лабораторная?

В этой работе добавим выбор изображения с устройства: пользователь нажимает кнопку, выбирает фотографию через системный интерфейс Android, а выбранное изображение появляется в форме объявления.

---

### Часть 1. Цель работы

Научиться открывать системный выбор изображений, получать `Uri` выбранной фотографии, показывать её в `ImageView` и сохранять состояние выбранного изображения при пересоздании `Activity`.

После выполнения работы пользователь сможет открыть форму подачи объявления, нажать "Выбрать фото", выбрать изображение на устройстве и увидеть предварительный просмотр.

### Часть 2. Подготовка экрана

#### Шаг 1. Создайте экран подачи объявления

Создайте экран подачи объявления:

* кнопку "Назад"
* область изображения `ImageView`
* поля "Название", "Цена", "Вид" и "Описание"
* кнопку "Создать"

#### Шаг 2. Подготовьте поля

В этом примере используется `ActivityResultLauncher` и системное действие `ACTION_OPEN_DOCUMENT`. Оно открывает системный интерфейс выбора файла. Фильтр `image/*` ограничивает список изображениями.

Внутри кода экрана подачи объявления создайте поля:

``` java
private ImageView ivSelectedImage;
private Uri selectedImageUri;

private final ActivityResultLauncher<String[]> imagePickerLauncher = registerForActivityResult(
            new ActivityResultContracts.OpenDocument(),
            uri -> {
                if (uri != null) {
                    selectedImageUri = uri;
                    ivSelectedImage.setImageURI(uri);

                    // cохраняем разрешение на доступ к выбранному документу
                    try {
                        getContentResolver().takePersistableUriPermission(
                                uri,
                                Intent.FLAG_GRANT_READ_URI_PERMISSION
                        );
                    } catch (SecurityException e) { }
                }
            }
    );
```

#### Шаг 3. Зарегистрируйте обработчик результата

В `onCreate()` после `setContentView()` найдите элементы интерфейса и подвяжите запуск выбора изображения:

``` java
ivSelectedImage = findViewById(R.id.iv_selected_image);
Button btnChooseImage = findViewById(R.id.btn_choose_image);

btnChooseImage.setOnClickListener(v ->
        imagePickerLauncher.launch(new String[]{"image/*"})
);
```

После лабораторной работы:

* на экране подачи объявления есть область предварительного просмотра изображения
* кнопка открывает системный выбор файлов, отфильтрованный по типу `image/*`
* выбранная фотография отображается в `ImageView`
