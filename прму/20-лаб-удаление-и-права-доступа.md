# Лабораторная работа №20

## Удаление объявления и права доступа

### О чем лабораторная?

В прошлой работе приложение научилось создавать и изменять объявления на сервере. Теперь добавим удаление объявления и проверим, что пользователь может удалить только свою запись.

Кнопка удаления будет отображаться на экране деталей только для владельца. Но окончательное решение все равно принимает сервер: наличие кнопки в приложении не является защитой.

### Главное

* удаление выполняется запросом `DELETE /items/{item_id}`
* перед удалением нужно показать подтверждение
* после успешного удаления экран не должен показывать удаленное объявление

---

### Часть 1. Изучите операцию API

Откройте документацию и найдите:

`DELETE /items/{item_id}`

Операция принимает идентификатор объявления в пути.

При успешном удалении сервер возвращает статус `204 No Content`. Тела ответа нет, поэтому не нужно пытаться прочитать `response.body()`.

Возможные результаты:

| Код | Значение |
| --- | --- |
| `204` | объявление удалено |
| `401` | пользователь не вошел или токен недействителен |
| `403` | объявление принадлежит другому пользователю |
| `404` | объявление не найдено |
| `422` | неверный идентификатор в запросе |

---

### Часть 2. Добавьте запрос в ApiService

Добавьте в `ApiService`:

```java
@DELETE("items/{item_id}")
Call<Void> deleteItem(
        @Path("item_id") int itemId
);
```

Используйте `Call<Void>`, потому что успешный ответ с кодом `204` не содержит JSON.

---

### Часть 3. Покажите кнопку только владельцу

На экране деталей уже загружается объект `ItemResponse`. В нем есть автор объявления:

```json
"author": {
  "id": "UUID",
  "username": "student"
}
```

Сравните имя автора с именем текущего пользователя. Текущего пользователя можно получить через `GET /user/me` или взять актуальное значение из профиля после успешной авторизации.

Пример:

```java
View deleteButton = findViewById(R.id.btn_delete_item);
String currentUsername = new ProfilePreferences(this).getUsername();

if (item.getAuthor() != null
        && currentUsername.equals(item.getAuthor().getUsername())) {
    deleteButton.setVisibility(View.VISIBLE);
}
```

Для чужого объявления кнопка должна оставаться скрытой.

Это только изменение интерфейса. Оно не заменяет проверку на сервере.

### Часть 4. Добавьте подтверждение удаления

Пользователь может нажать кнопку случайно. Перед запросом покажите `AlertDialog`:

```java
new AlertDialog.Builder(this)
        .setTitle("Удалить объявление?")
        .setMessage("Это действие нельзя отменить")
        .setNegativeButton("Отмена", null)
        .setPositiveButton("Удалить", (dialog, which) -> deleteItem(item.getId()))
        .show();
```

Метод `deleteItem()` должен выполнить сетевой запрос:

```java
private void deleteItem(int itemId) {
    ApiService api = RetrofitClient.getApiService(getApplicationContext());

    api.deleteItem(itemId).enqueue(new Callback<Void>() {
        @Override
        public void onResponse(
                Call<Void> call,
                Response<Void> response
        ) {
            if (response.code() == 204) {
                Toast.makeText(DetailsActivity.this,
                        "Объявление удалено", Toast.LENGTH_SHORT).show();
                finish();
            } else if (response.code() == 401) {
                showMessage("Сначала войдите в аккаунт");
            } else if (response.code() == 403) {
                showMessage("У вас нет прав на удаление этого объявления");
            } else if (response.code() == 404) {
                showMessage("Объявление уже удалено или не найдено");
            } else {
                showMessage("Не удалось удалить объявление");
            }
        }

        @Override
        public void onFailure(Call<Void> call, Throwable t) {
            showMessage("Ошибка сети. Объявление не удалено");
        }
    });
}
```

После успешного удаления `finish()` возвращает пользователя на предыдущий экран. При следующем обновлении ленты удаленного объявления там уже не будет.

### Часть 5. Самостоятельная работа

Доработайте удаление объявления в своем проекте:

1. добавьте метод `DELETE /items/{item_id}` в `ApiService`
2. покажите кнопку удаления только владельцу
3. добавьте подтверждение действия
4. обработайте ответы `204`, `401`, `403`, `404` и ошибку сети
5. после успешного удаления вернитесь к списку объявлений
6. обновите список и убедитесь, что удаленная запись исчезла

---

### Требования

* объявление удаляется через `DELETE /items/{item_id}`
* кнопка удаления видна только владельцу
* перед удалением отображается подтверждение
* успешный ответ `204` обрабатывается без чтения тела ответа
* после удаления пользователь возвращается к списку
* чужое объявление нельзя удалить
