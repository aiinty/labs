# Лабораторная работа №27

## Автоматическое обновление чата для нескольких пользователей

### О чем лабораторная?

В лабораторной работе №26 пользователь мог открыть чат и отправить сообщение. Но если другой пользователь отправил сообщение позже, открытый экран не узнает об этом сам.

В этой работе добавим автоматическую проверку новых сообщений. Приложение будет периодически запрашивать сервер и обновлять список чата без ручного нажатия кнопки.

### Главное, что нужно понять

* API само по себе не отправляет данные в приложение
* поэтому нам надо регулярно проверять сервер на наличие новых данных
* после получения новых сообщений список нужно обновить

---

### Часть 1. Загрузку сообщений отдельным методом

В `ChatActivity` должен быть метод, который загружает сообщения по текущему `itemId`:

```java
private void loadMessages() {
    api.getMessages(itemId, 1, 100).enqueue(
            new Callback<PaginatedResponse<MessageResponse>>() {
                @Override
                public void onResponse(
                        Call<PaginatedResponse<MessageResponse>> call,
                        Response<PaginatedResponse<MessageResponse>> response
                ) {
                    if (response.isSuccessful() && response.body() != null) {
                        showMessages(response.body().getItems());
                    }
                }

                @Override
                public void onFailure(
                        Call<PaginatedResponse<MessageResponse>> call,
                        Throwable t
                ) {
                    showMessage("Не удалось обновить сообщения");
                }
            }
    );
}
```

Вынесенный метод можно вызывать после открытия экрана, после отправки сообщения и из автоматического обновления.

### Часть 2. Добавьте периодическое обновление

Добавьте в `ChatActivity` поля:

```java
private final Handler handler = new Handler(Looper.getMainLooper());
private static final long REFRESH_INTERVAL = 5000;
private boolean refreshStarted = false;
```

Создайте задачу обновления:

```java
private final Runnable refreshRunnable = new Runnable() {
    @Override
    public void run() {
        loadMessages();
        handler.postDelayed(this, REFRESH_INTERVAL);
    }
};
```

Запускайте обновление, когда экран становится видимым:

```java
@Override
protected void onStart() {
    super.onStart();

    if (!refreshStarted) {
        refreshStarted = true;
        handler.post(refreshRunnable);
    }
}
```

Останавливайте задачу, когда экран скрывается:

```java
@Override
protected void onStop() {
    handler.removeCallbacks(refreshRunnable);
    refreshStarted = false;
    super.onStop();
}
```

Флаг `refreshStarted` не позволяет случайно запустить несколько одинаковых задач.

### Часть 3. Самостоятельная работа

Доработайте чат в своем проекте:

1. добавьте автоматическое обновление сообщений каждые 5 секунд
2. запускайте обновление в `onStart()`
3. останавливайте его в `onStop()`
4. не допускайте повторного запуска нескольких задач
5. проверьте обмен сообщениями на двух аккаунтах

---

### Требования к итоговой версии

* чат автоматически запрашивает новые сообщения
* интервал обновления составляет около 5 секунд
* обновление работает только при открытом экране чата
* после отправки сообщения список обновляется
* одинаковые сообщения не дублируются
* два пользователя видят сообщения друг друга
* временная ошибка сети не очищает уже показанную историю
* после закрытия чата автоматические запросы прекращаются
