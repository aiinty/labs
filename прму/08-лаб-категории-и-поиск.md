# Лабораторная работа №8

## Категории и поиск по элементам списка

### О чем лабораторная?

В предыдущей лабораторной вы собрали экран списка объявлений на `RecyclerView`. Теперь добавим в приложение категории и поиск: пользователь сможет фильтровать объявления по категории и искать по названию или описанию.

### Главное, что нужно понять

* категория - это дополнительное поле в модели данных
* фильтрация списка - это создание нового списка с нужными элементами
* поиск - это фильтрация по подстроке без учета регистра
* адаптер можно обновлять новым списком через `notifyDataSetChanged()`

#### Добавьте поле поиска

Добавьте в `activity_main.xml` поле ввода для поиска над списком:

```xml
<EditText

    android:hint="Поиск"
    android:padding="12dp"
    android:layout_margin="8dp" />
```

В коде вашего экрана найдите поле ввода и добавьте слушатель изменения текста:

```java
EditText etSearch = findViewById(R.id.et_search);
etSearch.addTextChangedListener(new TextWatcher() {
    @Override
    public void beforeTextChanged(CharSequence s, int start, int count, int after) { }

    @Override
    public void onTextChanged(CharSequence s, int start, int before, int count) {
        // здесь будет фильтрация
    }

    @Override
    public void afterTextChanged(Editable s) { }
});
```

Теперь создайте метод фильтрации в адаптере. Он принимает строку запроса и обновляет список в адаптере:

```java
private void filter(String query) {
    filtered = new ArrayList<>();
    for (Item item : allItems) {
        if (item.getTitle().toLowerCase().contains(query.toLowerCase())
                || item.getDescription().toLowerCase().contains(query.toLowerCase())) {
            filtered.add(item);
        }
    }
    adapter.updateList(filtered);
}
```

> **Подсказка:** храните полный список объявлений в отдельном поле `allItems`, чтобы фильтр всегда работал с исходными данными, а не с уже отфильтрованным списком (иначе после первой фильтрации - объекты пропадут навсегда)

Вызовите у адаптера `filter()` в `onTextChanged()`, передавая туда текст из поля ввода
