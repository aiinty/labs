# Лабораторная работа №15

## Экран деталей объявления и кэширование изображений

### О чем лабораторная?

В ленте пользователь видит только краткую информацию об объявлении. В этой работе добавим полноценный экран деталей: название, цену, описание, категорию, автора и изображение.

Изображение будем загружать с сервера при помощи библиотеки `Glide`. `Glide` автоматически использует кэш, поэтому ранее загруженная картинка не скачивается заново без необходимости.

### Главное

* для одного объявления используется `GET /items/{item_id}`
* идентификатор объявления передается в Intent при переходе на экран деталей
* `photo_url` может быть равен `null`
* загрузку изображений не нужно писать вручную через `InputStream`
* `Glide` умеет показывать изображение, временную заглушку и изображение ошибки
* кэш уменьшает количество сетевых запросов и ускоряет повторное открытие экрана

---

### Часть 1. Изучите ответ API

Откройте документацию и найдите:

`GET /items/{item_id}`

В путь передается идентификатор объявления. Сервер возвращает объект `ItemRead`:

```json
{
  "id": 10,
  "title": "Гитара",
  "description": "Акустическая гитара",
  "price": 7000,
  "deal_type": "sale",
  "photo_url": "ТУТ КАКАЯ-ТО ССЫЛКА",
  "category": {
    "id": 2,
    "name": "Музыка",
    "emoji": "🎸"
  },
  "author": {
    "id": "UUID",
    "username": "student",
    "about_me": null
  }
}
```

Поле `photo_url` может содержать `null`. Приложение не должно завершаться с ошибкой, если у объявления нет изображения.

### Часть 3. Передайте идентификатор объявления

В адаптере при нажатии на карточку передайте `id` объявления:

```java
holder.itemView.setOnClickListener(v -> {
    Intent intent = new Intent(context, DetailsActivity.class);
    intent.putExtra("item_id", item.getId());
    context.startActivity(intent);
});
```

В `DetailsActivity` получите идентификатор:

```java
int itemId = getIntent().getIntExtra("item_id", -1);

if (itemId == -1) {
    finish();
    return;
}
```

Не передавайте весь объект объявления через `Intent`. Передайте только его идентификатор и загрузите актуальные данные с сервера.

### Часть 6. Заполните экран деталей

В `DetailsActivity` выполните запрос:

```java
ApiService api = RetrofitClient.getApiService(getApplicationContext());

api.getItem(itemId).enqueue(new Callback<ItemResponse>() {
    @Override
    public void onResponse(
            Call<ItemResponse> call,
            Response<ItemResponse> response
    ) {
        if (response.isSuccessful() && response.body() != null) {
            ItemResponse item = response.body();

            titleView.setText(item.getTitle());
            priceView.setText(String.valueOf(item.getPrice()));
            descriptionView.setText(item.getDescription());

            if (item.getCategory() != null) {
                categoryView.setText(item.getCategory().getName());
            } else {
                categoryView.setText("Категория не указана");
            }

            if (item.getAuthor() != null) {
                authorView.setText("Автор: " + item.getAuthor().getUsername());
            }

            loadImage(item.getPhotoUrl());
        } else if (response.code() == 404) {
            showMessage("Объявление не найдено");
        } else {
            showMessage("Не удалось загрузить объявление");
        }
    }

    @Override
    public void onFailure(Call<ItemResponse> call, Throwable t) {
        showMessage("Ошибка сети. Проверьте подключение");
    }
});
```

Метод `loadImage()` можно вынести отдельно:

```java
private void loadImage(String imageUrl) {
    if (imageUrl == null || imageUrl.isEmpty()) {
        imageView.setImageResource(R.drawable.placeholder);
        return;
    }

    Glide.with(this)
            .load(imageUrl)
            .placeholder(R.drawable.placeholder)
            .error(R.drawable.placeholder)
            .into(imageView);
}
```

### Требования к итоговой версии

* нажатие на карточку открывает экран деталей
* экран запрашивает данные через `GET /items/{item_id}`
* отображаются основные данные объявления
* изображение загружается через Glide
* при отсутствии `photo_url` показывается заглушка
* экран не завершается с ошибкой при отсутствии изображения
