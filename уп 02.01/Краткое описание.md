# УП.02.01 Ролевая игра "Управление проектами"

## Состав команды

Одна команда состоит из **2–3 студентов**. В начале практики команда выбирает одного участника менеджером проекта.

Менеджер проекта:

- организует работу команды
- помогает распределять задачи
- следит за согласованностью документов
- представляет командный результат
- участвует в выполнении общих задач наравне с остальными участниками
- проставляет КТУ по каждой задаче в файле `КТУ.xlsx`

### День 1. Оценка трудоёмкости проекта

Изучить задание, составить перечень работ, выполнить индивидуальную и групповую оценку трудоёмкости.

### День 2. Инициация проекта

Подготовить устав проекта, техническое задание, иерархическую структуру работ, организационную структуру и матрицу ответственности.

### День 3. Планирование стоимости и рисков

Создать файл проекта в Microsoft Project, назначить ресурсы, рассчитать стоимость, подготовить предварительный перечень рисков, план реагирования, базовый план по стоимости и плановую стоимость плановых работ.

### День 4. Тестирование и контроль проекта

Подготовить план и сценарии тестирования, выполнить проверки, оформить протокол тестирования и зафиксировать выявленные несоответствия.

### День 5. Формирование команды проекта

Определить необходимые роли, составить реестр навыков, заявку на персонал и пример резюме, оценить кандидатов и сформировать команду.

### День 6. Подготовка отчёта и защита

Собрать результаты всех дней, оформить отчёт.

## Ежедневная оценка участия в команде

По итогам **каждого дня** заполните файл `КТУ.xlsx` и укажите коэффициент трудового участия каждого члена команды **по каждой выполненной задаче**.

В файле `КТУ.xlsx` находятся пять листов - по одному листу для каждого рабочего дня. На каждом листе уже указаны задачи и предусмотрены столбцы `ФИО 1`, `ФИО 2`, `ФИО 3`.

Перед началом работы:

1. замените заглушки `ФИО 1`, `ФИО 2`, `ФИО 3`
2. если в команде два человека, третий столбец оставьте пустым или укажите `—`
3. менеджер проставляет КТУ по каждой задаче на соответствующем листе

### Что такое КТУ

**КТУ - коэффициент трудового участия.** Он показывает долю вклада каждого в выполнение конкретной задачи.

### Как проставлять КТУ

Коэффициент указывается отдельно для каждого студента по каждой задаче. Используйте значения от `0` до `1` с шагом `0,1`:

| КТУ | Когда устанавливается |
| ---: | --- |
| 1,0 | Студент выполнил задачу полностью или единолично отвечает за её результат |
| 0,9 | Студент выполнил почти всю задачу, небольшой фрагмент выполнил другой участник |
| 0,8 | Студент выполнил основную часть задачи, остальная часть распределена между другими участниками |
| 0,7-0,6 | Студент выполнил большую часть задачи, но существенная часть принадлежит другим участникам |
| 0,5 | Вклад участников в задачу примерно равный |
| 0,4-0,2 | Студент выполнил отдельный небольшой фрагмент задачи |
| 0,1 | Студент выполнил минимальное действие в рамках задачи |
| 0,0 | Студент не участвовал в выполнении этой задачи |

### Порядок заполнения

1. В конце дня команда просматривает выполненные задачи
2. Каждый участник сообщает менеджеру, какую часть каждой задачи он выполнил
3. Менеджер сопоставляет заявленный вклад с фактическими результатами
4. Менеджер проставляет для каждого участника по каждой задаче значение КТУ от `0` до `1`
5. Менеджер вносит значения в `КТУ.xlsx` на лист соответствующего дня
6. Менеджер проверяет сумму КТУ всех участников по каждой задаче

### Главное правило суммы

Для каждой задачи сумма КТУ всех участников должна быть равна `1,0`.

Примеры:

| Задача | Участник 1 | Участник 2 | Участник 3 | Сумма |
| --- | ---: | ---: | ---: | ---: |
| Подготовка ТЗ | 0,5 | 0,3 | 0,2 | 1,0 |
| Расчёт стоимости | 0,7 | 0,3 | 0,0 | 1,0 |
| Оформление протокола | 1,0 | 0,0 | 0,0 | 1,0 |

Поэтому у каждого участника не может быть `1,0` в рамках одной задачи, если эту же задачу выполняли другие участники. Значение `1,0` означает полный вклад одного участника, а у остальных по этой задаче должно быть `0,0`.

Не выставляйте всем участникам автоматически одинаковый КТУ `1,0`. Если вклад в задачу был одинаковым, при двух участниках укажите `0,5` и `0,5`, а при трёх - например, `0,4`, `0,3` и `0,3`.

Если вклад оценён не целым значением, используйте шаг `0,1`: например, `0,7`, а не `0,75`.
