# День 5. Формирование команды проекта

## Что должно получиться к концу дня

К концу дня команда должна определить, какие специалисты нужны проекту, и подготовить документы для их подбора:

- реестр навыков
- заполненную заявку на персонал
- пример резюме кандидата

## Что вы получите на входе

Используйте:

- устав проекта
- техническое задание
- ИСР
- организационную структуру
- матрицу ответственности
- файл Microsoft Project
- выданное задание на разработку

## Шаг 1. Определите потребность в специалистах

Изучите работы ИСР и назначения ресурсов в MS Project. Для каждой работы ответьте:

- кто выполняет работу сейчас
- достаточно ли у этого исполнителя нужных навыков
- нужен ли отдельный специалист
- на какой срок он нужен
- какой результат он должен подготовить

Пример:

| Работа проекта | Необходимая роль | Почему нужна роль |
| --- | --- | --- |
| Проектирование интерфейса | UI/UX-дизайнер | В команде нет участника, отвечающего за макеты |
| Реализация расчёта стоимости | Разработчик | Нужно реализовать и проверить алгоритм |
| Подготовка тестов | Тестировщик | Требуется независимая проверка функций |
| ... | ... | ... |

Выберите одну или несколько ролей, для которых будете готовить документы по подбору.

## Шаг 2. Составьте реестр навыков

Реестр навыков показывает, что должен уметь специалист для выполнения конкретных задач проекта.

Создайте файл:

`01_Реестр_навыков.xlsx`

Заполните таблицу:

| Роль | Навык | Для какой работы нужен | Обязательный/желательный | Как проверить |
| --- | --- | --- | --- | --- |
| Тестировщик | Составление тестовых случаев | Проверка оформления заказа | Обязательный | Практическое задание |
| Тестировщик | Анализ требований | Проверка соответствия ТЗ | Обязательный | Вопросы на собеседовании |
| Тестировщик | Работа с баг-трекером | Регистрация дефектов | Желательный | Обсуждение опыта |
| ... | ... | ... | ... | ... |

В реестр включайте не только названия технологий. Навык должен быть связан с действием и результатом: «составляет тестовые случаи», «проектирует структуру базы данных», «оценивает риски», «готовит документацию».

Для каждой выбранной роли укажите минимум:

- 3 обязательных навыка
- 2 желательных навыка
- способ проверки каждого навыка

## Шаг 3. Составьте заявку на персонал

Подготовьте заполненный пример заявки:

`02_Пример_заявки_на_персонал.docx`

Заявка должна содержать:

1. название проекта
2. наименование требуемой должности или роли
3. количество специалистов
4. основание для подбора
5. задачи специалиста
6. результаты, которые он должен подготовить
7. обязательные навыки
8. желательные навыки
9. требования к опыту или уровню подготовки
10. период и объём привлечения
11. кому подчиняется специалист
12. с кем взаимодействует
13. срок закрытия заявки
14. критерии успешного подбора

### Пример заполнения заявки

```text
Проект: Приложение для службы такси
Роль: Тестировщик
Количество: 1 человек
Основание: в ИСР предусмотрены подготовка тестов и проверка функций заказа.
Задачи: разработать тестовые случаи, выполнить проверки, зарегистрировать дефекты,
подготовить протокол тестирования.
Обязательные навыки: анализ требований, составление тестовых случаев,
оформление результатов тестирования.
Желательные навыки: работа с баг-трекером, знание клиент-серверных приложений.
Период привлечения: этап тестирования и исправления ошибок.
Результат: протокол тестирования и перечень воспроизводимых дефектов.
...
```

Заявка должна объяснять, **зачем проекту нужен специалист**. Формулировки «нужен хороший программист» и «нужен ответственный человек» **недостаточны**.

## Шаг 4. Подготовьте пример резюме

Составьте пример резюме кандидата на одну из выбранных ролей:

`03_Пример_резюме_кандидата.docx`

В резюме укажите:

- имя кандидата
- желаемую роль
- краткую цель
- навыки
- учебные или проектные работы
- опыт, если он есть
- используемые инструменты
- образование
- ожидаемый вклад в проект

Резюме должно соответствовать заявке. Если в заявке обязательным является составление тестовых случаев, а в резюме нет подтверждения этого навыка, кандидат не полностью соответствует требованиям.

### Пример фрагмента резюме

```text
Кандидат: Иванова Анна Сергеевна
Желаемая роль: тестировщик

Цель: участие в проверке функций учебного проекта и подготовке документации
по результатам тестирования.

Навыки:
- анализ функциональных требований;
- составление тестовых случаев;
- проведение ручного тестирования;
- оформление протоколов и сообщений о дефектах;
- работа с таблицами и документацией.

Проектный опыт:
Подготовила тестовые случаи для функции оформления заказа, выполнила проверки
позитивных и негативных сценариев, оформила протокол и перечень дефектов.

...
```

Не используйте вымышленные коммерческие компании и опыт, который невозможно проверить. Для учебного кандидата достаточно указать учебные проекты и практические навыки.
