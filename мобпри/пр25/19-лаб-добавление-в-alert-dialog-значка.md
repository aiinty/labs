# Лабораторная работа №19

## Добавление в AlertDialog значка и заголовка

1. Не бойтесь **задавать любые** вопросы.

3. Советую читать текст, тут написано много **полезного**.

### О чем лабораторная?

На предыдущих занятиях мы познакомились с `AlertDialog` и научились добавлять в него кнопки. Сегодня улучшим внешний вид диалогового окна: значок, который поможет пользователю быстрее понять назначение сообщения.

В этой работе создадим несколько диалогов для разных ситуаций и сравним их оформление.

---

### Часть 1. Подготавливаем приложение

На главном экране разместите три кнопки:

- "Информация"
- "Предупреждение"
- "Подтверждение"

Каждая кнопка должна будет открывать свой диалог.

### Часть 2. Добавляем заголовок

У `AlertDialog.Builder` есть метод `setTitle()`, который устанавливает заголовок диалогового окна.

Например, заголовок может кратко объяснять назначение сообщения:

- "Информация"
- "Предупреждение"
- "Подтверждение действия"

> **Самостоятельное задание:** для каждой из трёх кнопок создайте диалог с подходящим заголовком и собственным сообщением. [**Если забыли как создавать диалог нажмите сюда**](https://github.com/aiinty/labs/blob/main/мобпри/пр25/17-лаб-создание-диалоговых-окон.md#часть-2-создаём-диалог)

### Часть 3. Добавляем значок

Значок помогает быстрее определить тип сообщения. Например, информационное окно может содержать значок информации, а предупреждение - значок внимания.

Для добавления значка используется метод:

```java
setIcon(...)
```

Он вызывается у объекта `AlertDialog.Builder` и принимает ресурс изображения.

Изображения можно хранить в папке `res/drawable`, а ресурс изображения можно получить через `R.drawable.имя_файла`.

> **Самостоятельное задание:**
>
> 1. Подберите или создайте три небольших изображения для разных типов сообщений
> 2. Поместите их в `res/drawable`
> 3. Добавьте подходящий значок в каждый диалог

### Часть 4. Настраиваем кнопки

У каждого диалога должно быть подходящее действие.

Например:

- информационный диалог - кнопка "Понятно"
- предупреждение - кнопки "Продолжить" и "Отмена"
- подтверждение - кнопки "Да" и "Нет"

> **Самостоятельное задание:** настройте кнопки каждого диалога так, чтобы пользователь понимал, какое действие произойдёт после нажатия. Достаточно вывести результат выбора на экран или показать сообщение с помощью `Toast`.

---

### Требования

1. Создано три диалоговых окна
2. У каждого диалога есть заголовок
3. У каждого диалога есть подходящий значок
4. Сообщения и кнопки соответствуют назначению окна
5. Обработчики кнопок работают корректно
6. Все текстовые данные вынесены в `strings.xml`
