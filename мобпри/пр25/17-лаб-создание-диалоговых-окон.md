# Лабораторная работа №17

## Создание диалоговых окон с кнопками

### Основные правила

1. Не бойтесь **задавать любые** вопросы.
2. Если хотите сделать что-то свое, то **предлагайте** - будем думать.
3. Советую читать текст, тут написано много **полезного**.

### О чем лабораторная?

Сегодня научимся создавать диалоговые окна с кнопками. Диалог позволяет показать пользователю сообщение и предложить выполнить действие, например подтвердить удаление или отменить операцию.

Создадим приложение, в котором пользователь нажимает на кнопку и видит диалог с вопросом и вариантами ответа.

---

### Часть 1. Подготавливаем интерфейс

В `activity_main.xml` разместите:

- `TextView` с заголовком "Диалоговые окна"
- `Button` с текстом "Показать диалог"
- `TextView` для отображения результата выбора пользователя

> Назначьте элементам понятные `id`

### Часть 2. Создаём диалог

Для создания простого диалогового окна в Android можно использовать класс `AlertDialog.Builder`. Он позволяет настроить заголовок, сообщение и кнопки диалога.

Основные методы:

| Метод | Назначение |
| --- | --- |
| `setTitle()` | Устанавливает заголовок |
| `setMessage()` | Устанавливает текст сообщения |
| `setPositiveButton()` | Добавляет основную кнопку |
| `setNegativeButton()` | Добавляет дополнительную кнопку |
| `show()` | Показывает диалог |

Cначала создаётся объект `AlertDialog.Builder`, затем настраиваются его элементы и в конце обязательно вызывается `show()`, чтобы он появился:

```java
new AlertDialog.Builder(this)
    .setMessage("Здесь ваше сообщение")
    .setPositiveButton("кнопка 1", (dialog, which) -> {
        // то что произойдет по нажатию на кнопку
    })
    .show();
```

> **Самостоятельное задание:** при нажатии на кнопку "Показать диалог" отобразите окно с вопросом "Вы хотите продолжить?" и двумя вариантами ответа "Да" и "Нет".

### Часть 3. Обрабатываем нажатия

Диалог не должен просто закрываться после нажатия. Приложение должно понимать, какой вариант выбрал пользователь.

Для этого у кнопок `AlertDialog` есть обработчики нажатий.

В обработчике можно выполнить любое действие: изменить текст на экране, показать сообщение или вызвать другой метод, например:

```java
    .setPositiveButton("кнопка 1", (dialog, which) -> {
        resultText.setText("Нажата кнопка 1");
    })
```

> **Самостоятельное задание:**
>
> 1. При нажатии "Да" выведите на экран текст "Вы выбрали: Да"
> 2. При нажатии "Нет" выведите на экран текст "Вы выбрали: Нет"

Подсказка: для изменения текста используйте `setText()` у `TextView`.

### Часть 4. Создаём диалог подтверждения

Теперь измените диалог так, чтобы он имитировал подтверждение действия.

Например, пользователь нажимает кнопку "Очистить данные", после чего приложение спрашивает, действительно ли он хочет выполнить действие.

Разместите на экране дополнительную кнопку "Очистить данные".

При её нажатии покажите диалог с вопросом "Вы действительно хотите очистить данные?".

> **Самостоятельное задание:**
>
> - При нажатии "Да" измените текст результата на "Данные очищены"
> - При нажатии "Нет" оставьте прежний результат

1. Создано приложение с кнопкой показа диалога

5. Создан диалог подтверждения действия
