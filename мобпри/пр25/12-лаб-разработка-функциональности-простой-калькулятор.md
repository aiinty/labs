# Лабораторная работа №12

## Реализация функциональности приложения "Простой калькулятор"

### Основные правила

1. Не бойтесь **задавать любые** вопросы.
2. Если хотите сделать что-то свое, то **предлагайте** - будем думать.
3. Советую читать текст, тут написано много **полезного**.

### О чем лабораторная?

На прошлом занятии мы создали интерфейс калькулятора. Сегодня научимся выполнять вычисления: получать числа из полей ввода, обрабатывать нажатия на кнопки и показывать результат.

---

### Часть 1. Подключаем элементы интерфейса

Откройте `MainActivity.java`.

В методе `onCreate()` после `setContentView()` найти элементы интерфейса с помощью `findViewById()`, например:

```java
editNumber1 = findViewById(R.id.edit_number1);
```

Необходимо получить:

- два поля ввода чисел
- четыре кнопки операций
- элемент для отображения результата

> **Самостоятельное задание:** объявите переменные подходящих типов и свяжите их с элементами разметки.

### Часть 2. Получаем числа из полей

Чтобы выполнить вычисление, необходимо получить текст из полей ввода и преобразовать его в числовой тип - мы же не можем разделить строку на строку.

Изучите следующий пример:

```java
String text = editNumber1.getText().toString(); // получаем из поля текст
double number = Double.parseDouble(text);       // преобразуем его в число
```

> **Самостоятельное задание:** получите значения из обоих полей и преобразуйте их в числа

### Часть 3. Реализуем сложение

Начнём с одной операции сложения, чтобы её сделать необходимо:

1. Получить первое число [(как получить число из поля ввода?)](#часть-2-получаем-числа-из-полей)
2. Получить второе число
3. Сложить их
4. Преобразовать результат в строку
5. Вывести результат в `TextView` для результата

И причем это должно происходить по нажатию на кнопку "+", потому ноебходим обработчик нажатия с помощью `setOnClickListener()`:

```java
buttonAdd.setOnClickListener(v -> {
    // Здесь будет код сложения
});
```

Для вывода результата в `TextView` используйте метод `setText()`

> **Самостоятельное задание:** реализуйте сложение по указанному алгоритму

### Часть 4. Добавляем остальные операции

По аналогии со сложением реализуйте вычитание, умножение и деление.

> **Самостоятельное задание:** самостоятельно реализуйте обработчики остальных трёх кнопок

### Часть 5. Обрабатываем ошибки

Пользователь может оставить поле пустым или попытаться разделить число на ноль. Приложение должно корректно реагировать на такие ситуации.

Реализуйте следующие проверки:

1. Если одно из полей не заполнено, покажите сообщение пользователю
2. Перед делением проверьте, не равен ли делитель нулю

Для отображения короткого сообщения можно использовать `Toast`:

```java
if (number2 == 0){
    Toast.makeText(
        this,
        "Деление на ноль невозможно",   // само сообщение
        Toast.LENGTH_SHORT              // сколько будет показываться сообщение?
    ).show();
}
```

Для проверки текста на заполненность можно использовать `isEmpty()`:

```java
String str = "Java";
if (str.isEmpty()){
    // не попадаем сюда
}

String str2 = "";
if (str2.isEmpty()){
    // попадаем сюда
}
```

> **Самостоятельное задание:** добавьте проверки перед выполнением вычислений

### Часть 6. Проверяем калькулятор

Проверьте приложение на следующих примерах:

| Первое число | Операция | Второе число | Ожидаемый результат |
| ---: | :---: | ---: | ---: |
| 2 | + | 3 | 5 |
| 10 | − | 4 | 6 |
| 3 | × | 5 | 15 |
| 20 | ÷ | 4 | 5 |
| 7 | − | 10 | −3 |
| 8 | ÷ | 0 | Сообщение об ошибке |

Также проверьте, что произойдёт, если оставить одно из полей пустым.

### Требования

1. Калькулятор выполняет сложение
2. Калькулятор выполняет вычитание
3. Калькулятор выполняет умножение
4. Калькулятор выполняет деление
5. Результат отображается на экране
6. Пустые поля обрабатываются без аварийного завершения приложения
7. Деление на ноль обрабатывается корректно
