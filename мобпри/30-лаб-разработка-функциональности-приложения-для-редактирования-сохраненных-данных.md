# Лабораторная работа №30

## Разработка функциональности приложения для редактирования сохраненных данных

### Цель работы

Разработать функционал для прилоежния с сохранением его состояние с помощью `SharedPreferences`.

### О чём лабораторная работа

В прошлой работе мы создали интерфейс игры "Кликер". Теперь добавим функциональность: игрок сможет зарабатывать монеты, покупать улучшения и увеличивать количество монет за одно нажатие.

Также реализуем сохранение прогресса, чтобы после закрытия и повторного запуска приложения игрок не терял заработанные монеты и купленные улучшения.

### Задание

Реализуем следующие возможности:

- начисление монет за нажатие на кнопку
- покупка улучшений за монеты
- увеличение награды за нажатие после покупки улучшения
- сохранение монет и уровня улучшений
- восстановление прогресса при запуске приложения
- сброс игрового прогресса

## Часть 1. Подготовка переменных

Откройте `MainActivity.java` и добавьте переменные для хранения игрового состояния:

```java
private int coins = 0;
private int coinsPerClick = 1;
private int upgradeCost = 10;
private int upgradeLevel = 0;
```

Здесь:

- `coins` - количество монет игрока
- `coinsPerClick` - количество монет за одно нажатие
- `upgradeCost` - стоимость следующего улучшения
- `upgradeLevel` - количество купленных улучшений

## Часть 2. Реализация нажатия

Теперь создадим единый метод для обновления интерфейса:

```java
private void updateInterface() {
    // обновляем количество монет
    coinsTextView.setText("Монеты: " + coins);

    // обновляем текст на подиси
    upgradeCostTextView.setText(
        "Стоимость: " + upgradeCost + " монет"
    );

    // обновляем текст на кнопке
    upgradeButton.setText(
        "Улучшение (+" + (upgradeLevel + 1) + " монет)"
    );
}
```

В методе `onCreate()` добавьте обработчик клика для кнопки `clickButton`, который будет содержать:

```java
coins += coinsPerClick;
updateInterface();
```

Теперь при каждом нажатии игрок будет получать монеты.

> **Обязательно** вызовите `updateInterface()` в конце `onCreate()`, чтобы интерфейс отображал начальные значения

## Часть 3. Покупка улучшений

Теперь добавьте обработчик клика для кнопки `upgradeButton` в `onCreate()`, который будет содержать:

```java
// проверяем хватает ли нам монет на улучшение
if (coins >= upgradeCost) {
    coins -= upgradeCost;

    upgradeLevel++;
    coinsPerClick++;
    upgradeCost *= 2;

    // не забываем все изменения отобразить на экране
    updateInterface();
}
```

Теперь игрок может покупать улучшения, если у него достаточно монет.

После каждой покупки количество монет за нажатие увеличивается на единицу, а стоимость следующего улучшения удваивается.

## Часть 4. Сохранение прогресса

Создайте поле для доступа к `SharedPreferences`:

```java
private SharedPreferences preferences;
```

В `onCreate()` после вызова `setContentView()` инициализируйте поле хранилища:

```java
preferences = getSharedPreferences(
    "clicker_settings",
    MODE_PRIVATE
);
```

А затем создайте метод для сохранения прогресса:

```java
private void saveProgress() {
    preferences.edit()
        .putInt("coins", coins)
        .putInt("coinsPerClick", coinsPerClick)
        .putInt("upgradeCost", upgradeCost)
        .putInt("upgradeLevel", upgradeLevel)
        .apply();
}
```

> **Обязательно** после этого добавьте `saveProgress()` *после изменения игрового состояния*: после клика и после покупки улучшения.

## Часть 5. Восстановление прогресса

Создайте метод для загрузки сохранённых данных:

```java
private void loadProgress() {
    coins = preferences.getInt("coins", 0);
    coinsPerClick = preferences.getInt("coinsPerClick", 1);
    upgradeCost = preferences.getInt("upgradeCost", 10);
    upgradeLevel = preferences.getInt("upgradeLevel", 0);
}
```

Вызовите `loadProgress()` в `onCreate()` после заполнения `preferences`, но до вызова `updateInterface()`.

Теперь игра будет восстанавливать сохранённые значения при каждом запуске.

## Часть 6. Сброс прогресса

Добавьте обработчик кнопки сброса:

```java
resetButton.setOnClickListener(v -> {
    coins = 0;
    coinsPerClick = 1;
    upgradeCost = 10;
    upgradeLevel = 0;

    saveProgress();
    updateInterface();
});
```

После сброса игрок начнёт игру заново, а старые сохранённые значения будут заменены начальными.
