### О чем лабораторная?

На прошлых занятиях вы научились создавать списки и добавлять пагинацию. Сегодня добавим поиск и фильтрацию - два важных механизма, которые есть практически в каждом приложении.

### Главное, что нужно понять

- **Поиск** - фильтрация списка по тексту, который вводит пользователь
- **Фильтрация** - отбор элементов по определённому критерию (категории, дате, статусу)
- **notifyDataSetChanged()** - метод для обновления списка после фильтрации

### Часть 1. Теория

#### Поиск по списку

Поиск позволяет пользователю быстро найти нужный элемент в списке. Для этого нужно:

1. Добавить поле ввода (`EditText`) в макет
2. Отслеживать изменения текста с помощью `TextWatcher`
3. Фильтровать список по введённому тексту

```java
editTextSearch.addTextChangedListener(new TextWatcher() {
    @Override
    public void beforeTextChanged(CharSequence s, int start, int count, int after) {}

    @Override
    public void onTextChanged(CharSequence s, int start, int before, int count) {
        adapter.filter(s.toString());
    }

    @Override
    public void afterTextChanged(Editable s) {}
});
```

#### Обновление списка после фильтрации

После фильтрации нужно обновить список в адаптере:

```java
public class BookAdapter extends RecyclerView.Adapter<BookViewHolder> {
    private List<Book> fullList;        // Полный список всех элементов
    private List<Book> filteredList;    // Отображаемый в данный момент список

    // ...

    public void filter(String text) {
        filteredList.clear();
        if (text.isEmpty()) {
            // если текст пустой - отображаем все
            filteredList.addAll(fullList);
        } else {
            // иначе ищем в каждом элементе эту строку
            String query = text.toLowerCase().trim();
            for (Book item : fullList) {
                if (item.getTitle().toLowerCase().contains(query) || 
                    item.getAuthor().toLowerCase().contains(query)) {
                    //если нашли совпадение, то добавляем в отфильтрованный список
                    filteredList.add(item);
                }
            }
        }

        notifyDataSetChanged(); // Не забываем сказать адаптеру перерисовать строчки
    }
}
```
