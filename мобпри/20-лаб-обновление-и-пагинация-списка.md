### О чем лабораторная?

На прошлых занятиях вы научились создавать списки с помощью RecyclerView. Сегодня добавим два важных механизма: обновление данных в списке и пагинацию (подгрузку новых элементов при прокрутке).

### Главное, что нужно понять

- **notifyDataSetChanged()** - метод, который говорит адаптеру: "данные изменились, перерисуй всё"
- **notifyItemInserted(int position)** - оповещает, что был добавлен один конкретный элемент
- **notifyItemRemoved(int position)** - оповещает, что был удален один элемента из списка
- **Пагинация** - подгрузка новых данных при прокрутке списка вниз

### Часть 1. Теория

#### Обновление списка

Когда данные в списке меняются, нужно сообщить адаптеру об этом. Для этого у **адаптера** есть несколько методов:

```java
// Полное обновление списка (перерисовывает все элементы)
adapter.notifyDataSetChanged();

// Добавление одного элемента
adapter.notifyItemInserted(position);

// Удаление одного элемента
adapter.notifyItemRemoved(position);

// Изменение одного элемента
adapter.notifyItemChanged(position);
```

**Важно:** `notifyDataSetChanged()` перерисовывает весь список, что может быть медленно для больших списков. Если вы знаете, какой именно элемент изменился, используйте `notifyItemChanged(...)`, `notifyItemInserted(...)` или `notifyItemRemoved(...)`.

#### Пагинация

Пагинация - это подгрузка следующего кусочка целых данных. Например, при прокрутке вниз загружается следующая порция элементов.

Для реализации пагинации нужно:

1. Отслеживать прокрутку списка с помощью `RecyclerView.OnScrollListener`
2. Определять, когда пользователь доскроллил до конца списка
3. Загружать новые данные и добавлять их в список

```java
recyclerView.addOnScrollListener(new RecyclerView.OnScrollListener() {
    @Override
    public void onScrolled(@NonNull RecyclerView recyclerView, int dx, int dy) {
        super.onScrolled(recyclerView, dx, dy);
        
        // Проверяем, что прокрутка идет вниз
        if (dy > 0) {
            LinearLayoutManager layoutManager = (LinearLayoutManager) recyclerView.getLayoutManager();
            int visibleItemCount = layoutManager.getChildCount();
            int totalItemCount = layoutManager.getItemCount();
            int firstVisibleItemPosition = layoutManager.findFirstVisibleItemPosition();

            // Если достигли конца списка
            if (visibleItemCount + firstVisibleItemPosition >= totalItemCount) {
                loadMoreData(); // Вызываем метод загрузки следующей порции
            }
        }
    }
});
```

Для расчета позиции используются методы LinearLayoutManager:

- **getChildCount()** - количество элементов, видимых на экране в данный момент
- **getItemCount()** - общее количество элементов в адаптере
- **findFirstVisibleItemPosition()** - порядковый номер первого видимого на экране элемента

#### Задание

Выберите одну из тем или предложите свою:

1. **Лента новостей** - при прокрутке вниз подгружаются новые новости

Требования к любой теме:

- Создайте адаптер с возможностью добавления новых элементов
- Реализуйте пагинацию: при прокрутке вниз подгружаются новые элементы

#### Подсказки

**Кнопка обновления:**

```java
buttonRefresh.setOnClickListener(v -> {
```
