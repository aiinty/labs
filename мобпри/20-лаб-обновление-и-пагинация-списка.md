### О чем лабораторная?

На прошлых занятиях вы научились создавать списки с помощью RecyclerView. Сегодня добавим два важных механизма: обновление данных в списке и пагинацию (подгрузку новых элементов при прокрутке).

### Главное, что нужно понять

- **notifyDataSetChanged()** - метод, который говорит адаптеру: "данные изменились, перерисуй все"
- **notifyItemInserted(int position)** - оповещает, что был добавлен один конкретный элемент
- **notifyItemRemoved(int position)** - оповещает, что был удален один элемента из списка
- **Пагинация** - подгрузка новых данных при прокрутке списка вниз

### Часть 1. Теория

#### Обновление списка

Когда мы изменяем обычный список, например добавляем или удаляем элемент, `RecyclerView` не всегда автоматически узнаёт об этом. Поэтому нужно сообщить **адаптеру**, какие изменения произошли:

```java
// Полное обновление списка (перерисовывает все элементы)
adapter.notifyDataSetChanged();
```

```java
// Добавление одного элемента
adapter.notifyItemInserted(позиция);
```

```java
// Удаление одного элемента
adapter.notifyItemRemoved(позиция);
```

```java
// Изменение одного элемента
adapter.notifyItemChanged(позиция);
```

Например, если мы добавили новость в самый конец списка:

```java
// добавляем новость
newsList.add(new News("Новая новость"));

// увежомляем адаптер, что на данной позиции список изменился 
adapter.notifyItemInserted(newsList.size() - 1);
```

Здесь `newsList.size() - 1` это позиция последнего добавленного элемента.

**Главное: сначала изменяем данные в списке, затем сообщаем адаптеру об изменении.**

#### Шаг 5. Реализуем пагинацию

Пагинация - это загрузка данных небольшими порциями. Например, сначала приложение показывает пять новостей, а при прокрутке вниз добавляет ещё пять.

В нашем примере мы будем имитировать загрузку, добавляя еще новостей.

##### Создаём метод загрузки

В MainActivity создайте метод `loadData()`, который добавляет в список ещё пять новостей:

```java
private void loadData() {
    int start = newsList.size() + 1;

    for (int i = start; i < start + 5; i++) {
        newsList.add(new News("Новость " + i));
    }

    // после добавления обязательно УВЕДОМЛЯЕМ адаптер
    adapter.notifyDataSetChanged();
}
```

##### Отслеживаем прокрутку

Чтобы понять, когда пользователь дошёл до конца списка, используем `RecyclerView.OnScrollListener`

Добавьте в `MainActivity` следующий код после настройки адаптера:

```java
recyclerView.addOnScrollListener(new RecyclerView.OnScrollListener() {
    @Override
    public void onScrolled(@NonNull RecyclerView recyclerView, int dx, int dy) {
        super.onScrolled(recyclerView, dx, dy);

        if (dy > 0) {
            LinearLayoutManager layoutManager = (LinearLayoutManager) recyclerView.getLayoutManager();

            int visibleItemCount = layoutManager.getChildCount();
            int totalItemCount = layoutManager.getItemCount();
            int firstVisibleItemPosition = layoutManager.findFirstVisibleItemPosition();

            if (visibleItemCount + firstVisibleItemPosition >= totalItemCount) {
                loadData();
            }
        }
    }
});
```

Разберём основные моменты:

- `dy > 0` - пользователь прокручивает список вниз.
- `getChildCount()` - количество видимых элементов.
- `getItemCount()` - общее количество элементов в списке.
- `findFirstVisibleItemPosition()` - позиция первого видимого элемента.

Когда пользователь доходит до конца списка, вызывается `loadData()`.

> Проверьте результат: прокрутите список вниз. В конце должны появляться новые новости
