# Лабораторная работа №24

## Тестирование приложения для ведения заметок

### Основные правила

1. Не бойтесь **задавать любые** вопросы
2. Если хотите сделать что-то свое, то **предлагайте** - будем думать
3. Советую читать текст, тут написано много **полезного**

### О чем лабораторная?

На прошлых занятиях мы разработали приложение для ведения заметок. Сегодня проверим его работу: попробуем создать, изменить и удалить заметки, найдем возможные ошибки и оформим результаты тестирования.

---

### Часть 1. Что такое тест-кейс

**Тест-кейс** - это описание одного проверочного сценария. Хороший тест-кейс содержит:

1. **Название** - что проверяем
2. **Предусловия** - что должно быть готово
3. **Шаги** - что делаем
4. **Ожидаемый результат** - что должны увидеть

Пример тест-кейса:

```text
Название: Создание новой заметки

Предусловия: Приложение открыто

Шаги:
  1. Нажать кнопку "+"
  2. Ввести заголовок "Покупки"
  3. Ввести содержимое "Молоко, хлеб, сыр"
  4. Нажать кнопку "Сохранить"

Ожидаемый результат: В списке появилась заметка "Покупки"
Фактический результат: ...
```

После выполнения проверки нужно записать фактический результат - то, что произошло на самом деле.

Если фактический результат совпадает с ожидаемым, тест пройден. Если нет - необходимо зафиксировать ошибку.

### Часть 2. Самостоятельная работа

По результатам работы подготовьте отчёт, включающий:

1. Список составленных тест-кейсов
2. Таблицу результатов тестирования
3. Результаты дополнительных проверок
4. Краткий вывод о состоянии приложения

В выводе ответьте на три вопроса:

1. Какие функции приложения работают правильно?
2. Какие ошибки удалось обнаружить?
3. Что нужно исправить в первую очередь?

#### Задание 1. Составьте тест-кейсы

Составьте не менее **7 тест-кейсов** для вашего приложения.

Обязательно проверьте следующие сценарии:

1. **Создание заметки.** Создайте заметку с заголовком и содержимым
2. **Редактирование заметки.** Измените заголовок существующей заметки и сохраните изменения
3. **Удаление заметки.** Удалите существующую заметку и проверьте, что она исчезла из списка
4. **Пустая заметка.** Попробуйте сохранить заметку без заголовка и содержимого
5. **Длинный заголовок.** Создайте заметку с длинным заголовком и проверьте, как он отображается в карточке
6. **Многострочный текст.** Создайте заметку с текстом из нескольких строк и проверьте его отображение
7. **Повторное редактирование.** Измените одну заметку несколько раз и проверьте, что сохраняется последняя версия

Для каждого сценария заполните шаблон из [первой части](#часть-1-что-такое-тест-кейс)

#### Задание 2. Проведите тестирование

Пройдите по каждому тест-кейсу и заполните таблицу:

| № | Тест-кейс | Результат | Комментарий |
| --- | ----------- | ----------- | ------------- |
| 1 | Создание новой заметки | PASS / FAIL | |
| 2 | Редактирование заметки | PASS / FAIL | |
| ... | ... | ... | |

Если вы составили дополнительные тест-кейсы, добавьте их в таблицу.

> **PASS** - фактический результат **соответствует** ожидаемому
>
> **FAIL** - фактический результат **отличается** от ожидаемого

В комментарии кратко укажите, что именно произошло. Если тест не пройден, опишите обнаруженную проблему.

#### Задание 3. Граничные случаи

Проверьте приложение на необычных ситуациях:

| Ситуация | Что проверить | Комментарий |
| ---------- | --------------- | ------------- |
| Спецсимволы | Корректно ли отображаются символы `<`, `>`, `&` и кавычки? | |
| Быстрые нажатия | Что произойдёт, если несколько раз быстро нажать кнопку сохранения? | |
| Поворот экрана | Сохраняются ли введённые данные после поворота устройства? | |
| Перезапуск приложения | КСохраняются ли заметки после закрытия и повторного запуска приложения? | |
| Большое количество заметок | Можно ли прокручивать список и открывать нужные заметки? | |

Проверьте их и запишите результаты в отчёт.
