# Защита курсового проекта

## 1. Что должно быть в выступлении?

Выступлением является речь и сопровождающая ее презентация, оно должно укладываться в установленное время - **до 10 минут максимум**. Примерный план выступления:

| № | Содержание | Примерное время |
| --- | --- | --: |
| 1 | Тема курсового проекта, ФИО | |
| 2 | Актуальность, проблема и назначение системы/приложения | 2 мин |
| 3 | Пользователи и  Use Case диаграмма | 1 мин |
| 4 | Проектирование данных (ERD) | 1 мин |
| 5 | Проектирование интерфейса | 1 мин |
| 6 | Оценка трудоемкости | 1 мин |
| 7 | Вывод | 1 мин |
| 8 | Ответы на вопросы | 3 мин |
| Итого | | **10 мин** |

Можно изменяить количество и последовательность слайдов в презентации в зависимости от ваших желаний, но содержание презентации должно отражать содержание курсового проекта.

**Требования к выступлению:**

- Минимальное чтение с презентации/заготовленной речи
- Можете ответить на вопросы по содержанию курсового проекта
- Презентация должна содержать не менее 6 слайдов
- Презентация должна соответствовать содержанию курсового проекта

## 2. Критерии оценки

| Критерий оценивания | Баллы |
| --- | ---: |
| Понимание предметной области | 15 |
| Качество проектирования | 35 |
| Качество документации | 15 |
| Ответы на вопросы | 25 |
| Оценка выступления | 10 |
| **Итого** | **100** |

- **90–100 баллов** - 5
- **65–89 баллов** - 4
- **50–64 балла** - 3
- **менее 50 баллов** - 2
